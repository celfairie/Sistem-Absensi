# Sistem Absensi Berbasis Kamera

Aplikasi absensi sederhana yang menggunakan fitur kamera (webcam) untuk melakukan check-in harian. Dibuat untuk mempermudah proses pendataan kehadiran dengan verifikasi foto.

## Fitur Utama
- **Real-time Camera:** Mengambil foto langsung dari browser.
- **Data Capture:** Menyimpan data nama, NPM, dan bukti foto ke database.
- **Dashboard Records:** Melihat riwayat absensi yang sudah dilakukan.
- **Responsive UI:** Tampilan yang rapi di berbagai perangkat.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Bootstrap 5)
- **Backend:** PHP (Native)
- **Database:** MySQL
- **Other:** JavaScript (WebRTC API untuk kamera)
